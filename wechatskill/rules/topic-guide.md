# 选题与对标指南

> 选题定生死——好选题是爆款的前提。本文整理了选题方法论、对标账号体系、赛马机制原理，帮助你系统化地找到高潜力选题。

---

## 一、推荐机制：赛马机制

理解平台算法是写出爆款的基础。

### 赛马机制原理

每天有海量文章发布，平台通过「赛马机制」筛选优质内容：

```
你发布文章
  → 系统分发给几百人（初始流量池）
  → 系统根据数据打分（完读率、点赞、转发、评论）
  → 数据好 → 进入更大流量池，与更多文章竞争
  → 再次胜出 → 继续进入更大流量池
  → 循环往复 → 阅读量 5 万 → 10 万 → 100 万
  → 数据不好 → 停留在当前流量池，不再推荐
```

### 关键数据指标

| 指标 | 说明 | 提升方法 |
|------|------|---------|
| **完读率** | 读者读完全文的比例 | 控制字数、设置钩子、不啰嗦 |
| **点赞率** | 点赞数/阅读数 | 引发共鸣、提供价值 |
| **在看率** | 点击「在看」的比例 | 正文中自然引导 |
| **转发率** | 转发数/阅读数 | 内容有社交货币属性 |
| **评论率** | 评论数/阅读数 | 设置争议话题、开放提问 |

### 如何利用赛马机制

1. **寻找蓝海领域**：竞争文章少 → 更容易胜出 → 更快进入大流量池
2. **选择发布时间**：与对标账号错开发布时间（对标 8 点发，你 7 点发）
3. **提升完读率**：开头设置钩子，中间和结尾留下悬念，吸引读者不断往下看
4. **引导互动**：在文中适当引导点赞、收藏、转发（但不能诱导，需自然）
5. **差异化竞争**：与对标爆款做差异化——人无我有，人有我优

## 二、对标账号体系

### 对标账号分级

| 级别 | 特征 | 用途 |
|------|------|------|
| **A 类** | 大量粉丝 + 高互动率 | 学习长期运营策略 |
| **B 类** | 短期出现 10w+ 爆文 | 学习爆款选题和标题 |
| **C 类** | 稳定 2w 左右阅读 | 学习稳定输出方法 |
| **D 类** | 一直起不来的账号 | 避免踩坑、引以为戒 |

### 寻找对标的方法

#### 方法一：微信搜一搜

1. 根据你的赛道想一个**关键词**（如情感领域 → 婆婆、婆媳）
2. 在微信「搜一搜」中搜索该关键词
3. 优先选择 **10w+ 阅读**的文章
4. 进入文章所在的公众号，扒所有爆款标题
5. 从标题中提取更多关键词，继续搜索 → **套娃式获取关键词**

#### 方法二：套娃式关键词发散

```
初始关键词（如：裁员）
  → 搜索找到爆款文章
  → 从爆款标题中提取新关键词（国企央企、欠薪、降薪、亏损）
  → 用新关键词继续搜索
  → 获得更多爆款文章和对标账号
  → 循环往复，源源不断
```

#### 方法三：其他平台

- **脉脉**：职场爆料、大厂信息（适合职场类）
- **知乎**：深度讨论、社会议题（适合观点类）
- **微博**：娱乐热点、实时热搜（适合热点类）
- **豆瓣**：影评剧评、书评（适合剧评/清单类）
- **头条/百家号**：各类频道分类，标题即关键词

### 选择对标爆款文章的标准

1. **阅读量**：首选 10w+，其次 7-8w+
2. **发布时间**：最近 3 个月内（爆过的内容大概率还会爆）
3. **账号注册时间**：最好也是最近 3 个月注册的低粉号（排除粉丝红利因素）

## 三、选题方法论

### 选题的核心逻辑

一篇文章由三部分组成：
- **选题**：文章的骨架，决定文章最终的样子
- **正文**：文章的血肉，填充骨架丰富细节
- **标题**：文章的外衣，决定能否被用户一眼发现

### 六大赛道推荐

| 赛道 | 特点 | 适合人群 |
|------|------|---------|
| 热点类 | 经久不衰，流量大 | 关注时事、反应快的人 |
| 历史类 | 长期深耕，素材丰富 | 对历史有积累的人 |
| 剧评类 | 相对稳定，素材多 | 喜欢追剧看电影的人 |
| 美食类 | 涨粉快，受众广 | 喜欢做饭/吃的人 |
| 职场类 | 话题性强，共鸣度高 | 有职场经历的人 |
| 情感类 | 受众广，爆款频出 | 善于讲故事的人 |

**建议**：选 1 个赛道、2 个细分方向，坚持创作。

### 选赛道的评分法

给自己打分，满分 100（每项 25 分）：

| 维度 | 评估标准 |
|------|---------|
| **感兴趣** | 有意愿日更，没收益也愿意写 |
| **擅长** | 有相关技能和经验，愿意复盘精进 |
| **市场需求** | 供需关系如何，竞争激烈程度 |
| **输出意愿** | 是否愿意改变习惯、持续输出 |

- 60 分以上：可以入手
- 40-60 分：看看哪方面需要克服
- 40 分以下：考虑换赛道

详见 [style-guide.md](style-guide.md) 第七节「选题的三大特征」。

## 四、各赛道选题技巧

### 职场类
- **素材来源**：脉脉（大厂爆料）、知乎、BOSS 直聘
- **爆款方向**：裁员、薪资泄露、职场故事
- **注意**：针对网友评论讨论，不自我想象、不造谣、不攻击企业，保持客观

### 热点类
- **指点江山类**：知乎自然爆款 > 知乎热榜 > 微博热榜（选尖锐的内容）
- **娱乐热点类**：微博有「热」字可选，有「沸」字优先选，有「爆」字要抢速出文
- **养生热点类**：结合节气 + 健康热榜，只往古代习俗靠，不给医学建议

### 剧评类
- **热点+剧评**：追正在热播的剧/电影，趁热度写出多角度影评
- **经典老剧**：《知否》《甄嬛传》等，流量大、信息量大，一部剧能写几百篇

### 历史类
- **追热点历史**：从当下热点找到历史契合点（需高写作功底）
- **中规中矩写法**：选自己喜欢的历史人物/事件，按基调梳理
- **写法**：人物结局反转 / 性格反面 / 事件总结 / 盘点类

### 情感类
- **素材要求**：至少包含以下 8 要素中的 3 个以上：
  曲折性、情绪、信息增量、民生问题、名人、性、暴力、金钱
- **素材来源**：各大平台找有爆款潜质的故事（共鸣、感人、争议、异常）

## 五、选题避坑

### 绝对红线

| 红线 | 说明 |
|------|------|
| **党史军史** | 只能写正面内容，1840 年后中国相关历史慎写 |
| **吃人血馒头** | 不利用逝者做文章、不编造细节、不消费他人痛苦 |
| **财经/健康** | 需要职业认证才能写，无资质不碰 |

### 隐性坑

1. **违禁词**：发文前过「句易网」检测（很多日常词也是违禁词）
2. **标题党嫌疑**：没有违禁词但被限流，检查标题是否夸大
3. **竞品平台关键词**：不要提微博、抖音等竞品名称
4. **企业名称**：用「某通讯公司」「某银行」替代具体企业名
5. **人物命名**：不用大众化真名，用昵称（详见 risk-check.md 人物命名避坑）

## 六、拆解爆款文章模板

找到爆款后，快速拆解的方法：

1. **通读全文**，确定文章核心意思
2. **找转折词**：「但是」「为何」「不过」「然而」标记段落边界
3. **浓缩每段**：把转折词上下的内容各浓缩为一句话
4. **得出模板**：按开头/中间/结尾的结构整理出模板
5. **以自己的话复写**：用自己的语言重新展开

**核心原则**：掌握「拆解思维」比记住具体模板更重要，不同领域的模板不同，但拆解方法通用。

## 七、HKR 选题质检法（来自 khazix-writer）

> 每个选题动笔前必过 HKR 三关。比"异常+多平台验证+有话说"更精炼，适合快速判断。

动笔前每个选题必须通过：

| 维度 | 全称 | 核心问题 |
|------|------|---------|
| **H** | Happy / 有趣 | 足够有趣、有悬念吗？标题和开头能让人好奇想点开吗？ |
| **K** | Knowledge / 信息量 | 有信息量吗？看完能学到新东西吗？ |
| **R** | Resonance / 共鸣 | 能戳中情绪吗？让人"对对对我也这么想"？ |

**评分标准**：
- S 级选题：三项兼备 → 最有爆款潜力
- 及格选题：至少占两项 → 可以写
- 危险选题：只占一项 → 重新审视选题方向
- 放弃：零项 → 坚决不写

**与「好选题三大特征」的关系**：
- HKR 偏向**内容层面**：选题本身是否有料
- 三大特征（异常/多平台验证/有话说）偏向**流量层面**：选题是否能跑量
- 两套标准可以叠加使用：先用 HKR 判断内容价值，再用三大特征判断流量潜力

## 八、AI 赛道内容方法论（来自 khazix-writer）

> 针对 AI/科技/互联网类内容特别有效的选题方法，非 AI 赛道也可参考选题来源部分。

### 选题来源矩阵

| 平台 | 用途 | 具体操作 |
|------|------|---------|
| **X（Twitter）** | 抓一手资讯 | 每日搜索"AI"关键词，关注 AI 博主和公司动态 |
| **Reddit** | 看真实用户反应 | r/artificial、r/ChatGPT、r/singularity（100+ upvote 算比较火）|
| **小红书** | 大众舆论场话题焦点 | 重点关注评论区，监测「有没有」「推荐」等关键词 |
| **即刻** | AI 博主/产品创意/行业洞察 | 关注创业者和博主的碎片分享 |
| **微博/抖音/B站** | 判断是否真正"破圈" | 至少两三个平台同时火才算真正破圈 |
| **读者社群** | 真实痛点 | 监测群友的难点、痛点、经常出现的需求 |

### 选题角色代入法（发散思考）

审视选题时代入不同角色：

- **"一个很忙的普通用户"**：能帮我省时间/解决具体麻烦吗？
- **"一个爱玩的朋友"**：够有趣吗？能让我产生"卧槽还能这样？"的惊叹？
- **"一个焦虑的学习者"**：能让我学到新东西、有新角度吗？

### 选题类型参考（按内容形态）

| 类型 | 描述 | 对应文章模板 |
|------|------|------------|
| **产品评测+推荐** | 实测体验为主，有明确好恶判断 | [产品体验型](../templates/产品体验型.md) |
| **玩法+教程分享** | 手把手教读者操作，核心是 Prompt 和步骤 | [工具分享型](../templates/工具分享型.md) |
| **现象访谈类** | 互联网现象解读、人物专访故事 | [现象解读型](../templates/现象解读型.md) |
| **认知观点** | 对事件的深度分析、论文分享 | 观点型 |
| **调查实验** | 自己动手做好玩的东西，展示发现 | [调查实验型](../templates/调查实验型.md) |

### 创意案例工作法（三类锚点）

**选题时可以从三个方向发散创意：**

1. **热点锚点**：当下最火的电影/电视剧/社会事件/网络热梗 → 流量最大公约数
2. **痛点锚点**：用户最高频、最头疼的问题 → 实用价值
3. **炫技点锚点**：工具/产品本身最颠覆的核心功能 → 技术惊叹

**把创意包装成微型故事（爆款创意框架）**：
1. 亮出「挑战」：想解决什么问题？
2. 展示「脑洞」：想到了什么骚操作？
3. 秀出「过程」：怎么一步步实现的？（截图、核心 Prompt）
4. 引爆「结果」：最终那个让人"卧槽"的作品

> 准则：案例必须有独立的观赏价值、创意价值和启发价值。如果自己都 High 不起来，坚决不发。
