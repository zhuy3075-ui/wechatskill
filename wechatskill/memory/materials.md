# 素材库

> 收集无明确作者/风格归属的通用素材。
> 指定作者、指定账号、指定风格的素材必须写入 `memory/styles/[风格名].md`，不得写入本文件。
>
> **与金句库的分工**：
> - `golden-sentences.md`：无指定风格创作中产出的原创金句
> - `materials.md`（本文件）：无明确风格归属的外部素材（案例、数据、结构、标题技巧等）
> - `memory/styles/[风格名].md`：对应风格的标题、金句、素材、反馈记忆

## 使用说明

### 素材标准格式

每条素材必须包含以下字段（含素材ID，用于去重和跨文件引用）：

```text
- [M-001] [素材内容摘要（1-3句话概括核心信息）]
  来源：《文章标题》/ [机构名] / [其他来源]
  赛道：[一级赛道 > 二级赛道]
  适用类型：[干货/故事/观点/清单/热点]（可多选，用+连接）
  标签：#关键词1 #关键词2 #关键词3
  质量分：1-5（5=高复用高价值）
  添加日期：YYYY-MM-DD
  已用于：（使用后记录：《文章标题》日期）
```

**素材ID 规则**：
- 格式：`M-XXX`（M 代表 Material，XXX 为三位递增编号）
- 新增素材时取当前最大编号 +1
- 删除素材后编号不回收，避免引用失效
- 其他文件（benchmarks.md、performance.md）通过素材ID引用素材

### 检索方式

写作时按以下维度筛选素材：
- **按赛道**：找同赛道素材（如：职场成长相关的案例）
- **按标签**：找关键词匹配的素材（如：#焦虑 #内卷）
- **按类型**：找适合当前文章类型的素材（如：故事型需要案例故事）
- **按分类**：找特定用途的素材（如：需要数据论据支撑观点）
- **按质量分**：优先使用质量分 ≥4 的素材

### 风格隔离

- 如果素材来源明确属于某个作者、账号或风格，写入 `memory/styles/[风格名].md`。
- 指定风格写作时，不从本文件学习标题模式、金句模式、结构模式或语气偏好。
- 本文件只提供无风格通用事实素材，不覆盖 `styles/[风格名].md` 和 `memory/styles/[风格名].md`。

### 容量与淘汰

- 总量上限 200 条
- 超过 6 个月未使用的移到底部「冷素材区」
- 每积累 50 篇文章全面清理一次
- 已用 3 次以上的标记为「高频素材」

### 月度健康检查模板

每月执行一次：

| 指标 | 当前值 | 目标值 | 处理动作 |
|------|------|------|------|
| 素材总量 |  | ≤200 | 超限则先清理低质量和重复项 |
| 冷素材占比 |  | <30% | 超标则归档或淘汰 |
| 高频素材占比 |  | 10%-25% | 过低说明复用不足，过高说明素材老化 |
| 平均质量分 |  | ≥3.8 | 低于目标时补充高质量来源 |
| 重复素材率 |  | <8% | 执行去重并保留高质量条目 |
