# 现象解读型文章模板

> 来源：khazix-writer 写作原型提炼
> 适用于：观察到一个有趣的现象，然后层层深入分析。好奇心驱动 → 研究 → 知识掉落 → 哲学升维。

## 核心写法

**好奇心驱动**：从"我发现了一件有趣的事"出发，带着读者一起思考。

好奇心驱动 → 研究发现 → 知识掉落 → 哲学升维（可选）。

## 经典结构

```
标题：[一个引发好奇的现象] + [出人意料的发现]
示例：「AI 看不到爱心，背后原因让我想了很久」
      「三宫格图片刷屏背后，藏着一个十年前的心理学秘密」

---

## 开头（100-150 字）

[现象呈现]：你看到/注意到了什么有趣的事？
[好奇心触发]：这件事哪里让你感觉"不对劲"或"有意思"？
[追问]：你打算怎么研究？或者你已经发现了什么？

---

## 中间：层层深入

[表层分析]：这个现象表面上是什么原因？
[追问]：但这个解释解释不了什么？还有哪里奇怪？
[深层原因]：你找到的更深层的解释（可以是论文/历史/数据）
[知识掉落]：顺带引出一个相关的有趣知识（学科背景/历史事件）
[哲学升维]（可选）：把这件事连接到更大的人类命题

---

## 结尾（100-200 字）

[感悟或洞察]：这件事让你想到什么更深的东西
[余韵]：留一个余味或开放性问题
[回环]（可选）：呼应开头

```

## 经典案例结构拆解

### 「AI 看不到爱心」→ 哲学感悟
```
观察：AI 模型都识别不出爱心符号
表层：它们描述成圆形/曲线
追问：为什么？这是模型能力问题吗？
发现：找到论文——时间盲视（Temporal Blindness）
知识掉落：格式塔心理学「共同命运法则」
升维：流中的我们 vs 帧中的 AI
结尾金句："我们活在流中，而 AI 活在帧中。"
```

### 「三宫格图片刷屏」→ 人生叙事需求
```
观察：三宫格 AI 图片突然刷屏
表层：这是一种新的美学潮流
追问：为什么偏偏是三宫格？
发现：连接到十年前加黑边的照片潮流
深层：人需要用审美框架安放自己的人生故事
升维：每个人都需要一个故事来安放自己的人生
```

## 知识掉落技法（核心）

知识不是"下面我来科普"，而是"我突然想起来这个"：

**正确**：
> 突然想起了以前做交互设计的时候，有一个几乎刻在我血液里的心理学，叫格式塔心理学。里面有一个非常牛逼的原则……

**错误**：
> 下面我来简单介绍一下格式塔心理学。格式塔心理学起源于……

## 升维路径参考

| 现象 → 升维方向 |
|---|
| AI/科技现象 → 人性/哲学/历史类比 |
| 社会现象 → 心理学/社会学洞察 |
| 商业现象 → 历史规律（电力史/互联网史）|
| 文化现象 → 人类共同的情感需求 |
| 个人经历 → 普遍的人生洞察 |

## 疑问句制造节奏刹车

关键处用疑问句让读者停一秒，准备接收新信息：

> 为啥复制一遍，会有效果呢？

> 听着很难理解对吧。我还是用大白话举个例子。
