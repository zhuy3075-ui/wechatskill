# 梁靠谱派（实战导师派）

语气：直白、有料、江湖气，像一个见过世面又愿意掏心的商业前辈。
结构：触发事件/学员提问 → 自我迭代（1.0/2.0/3.0）→ 类比打通 → 哲学收尾。
适用：销售成交、个人IP建设、社群运营、职场人性、女性创业、身心管理
关键词：销冠、IP、成交、迭代、实战、学员故事、人性洞察
全局偏好：遵守短句密度与标点密度上限，优先可读性。
风格偏好：实战权威感强、自我揭露真实、类比密度高、引文用来升华而非炫学；允许适度情绪词和真实反应，减少模板化总结感。
短句策略：以2-4句组成一个自然段为主，长短段错落；单句成段仅用于情绪反转和关键判断，每篇不超过4处，避免连续短句造成AI味。
标点策略：「」代替引号做强调，逗号延伸思路（不轻易用句号断句），感叹号节制。
俚语方言：适量使用"知道不"、"晓得"、"就是"等口语，保持平易感，非刻意东北味。

说明：来源于公众号「梁靠谱」的写作风格提炼，适合销售/IP/商业认知/人性关系类内容，
以"销冠导师"的实战权威 + 真人温度 + 类比思维 + 强判断标题为核心特征。
样本：已迭代至220篇（2025年7月-2026年5月），覆盖销售成交、个人IP、自媒体、AI、关系学、身心管理、创业心力等主题。

## 全量样本校准（2026-05-29）

基于 `梁靠谱/` 文件夹 220 篇文章和标题复盘后的执行校准：

- 文章长度多为短中篇，正文中位数约1100字；常见有效区间是800-1600字，不必强行写到长文
- 排版以短段为主，但不是一句一段到底；段落中位长度约46字，常用2-3句承载一个完整小意思
- 标题高度依赖冲突判断：220个标题里，约九成带逗号，约四成带数字/金额/年份/比例，常见"人群点名 + 反常识判断 + 结果后果"
- 正文常用"具体事件/学员问题/身体感受/热搜人物"开场，再转到商业、人性或心力判断
- 语言不是温吞的导师感，而是"见过太多之后的直白"：可以损、可以狠、可以调侃，但最后要落到解决问题和自我负责
- 高频口语转场是"就是、然后、其实、你看、我觉得、说实话"，用来制造真人口述感，不要替换成论文式连接词
- 近期文章更常见单点洞察：一个事件讲透一个判断，少铺陈，少完整方法论，结尾可以锋利收住或轻度转化

## 开头技法（5 种）

### 学员提问型（最高频）
从一个学员的困惑切入，迅速建立"我有实战资历"的可信度：
> 我经常会回答这样的问题，做咨询的来访者，首先对业绩有困惑，对增长有期待，于是就找我做咨询……

✅ 适用场景：方法论、业务技巧、社群运营类文章
✅ 关键：先描述学员处境，再带出你的解法，不要开门见山直接说"今天我要讲xxx"

### 地狱笑话/戏谑开场
用一个黑色幽默或荒诞事实先抓住注意力，再说"后来我明白了"：
> 以前听过一个地狱笑话，说精神病院里，男的得病因为创业失败，女的得病因为不被爱，当时不懂，后来我长大了，开始创业，开始交付客户。然后发现了这事儿可能是真的。

✅ 适用场景：销售心理、人性观察、行业痛点类文章
✅ 关键：笑话/荒诞事实必须和正文主题强相关，不是单纯搞笑

### 老话/经典引入型
用一句古话、影视台词或名人金句打头，立刻扣题展开：
> 老话说，「食色性也」。你听没听过身边的人说一些话……

✅ 适用场景：关系学、人性分析、价值观类文章
✅ 关键：引用后立即用具体生活场景接地气，不要抽象继续抽象

### 个人直白型
直接亮出自己的处境/经历，让读者立刻感受到"真人感"：
> 前一阵子去福建出差，中间不知道哪里的劲儿没用对，脖子就开始疼了……

✅ 适用场景：身心管理、个人成长、生活感悟类文章
✅ 关键：细节越具体越好（福建、出差、飞机落地直奔按摩店），不要泛泛"最近我遇到了xxx"

### 场景追问型
描述一个具体争议场景，直接用问句或判断句抛出核心议题：
> 什么是真正的「对抗路夫妻」呢？其中一个人说，我为了你爸的事特意跟xx吃饭走关系，另一个人说，那怎么的我还给你磕一个啊！

✅ 适用场景：两性关系、家庭议题、社会观察类文章
✅ 关键：场景要够具体、够日常，读者能立刻代入或见过这种情况

## 标题公式（全量样本高频）

梁靠谱的标题不是温和概括，而是先制造一个"我想点开看她怎么骂/怎么讲"的心理钩子。标题要像一句已经有立场的话，不像目录。

### 公式一：人群点名 + 负面后果
适合销售、创业、IP、自媒体、亲密关系主题。

- 销售们，别再自轻自贱，把自己变成怨妇！
- 问客户还有什么顾虑的销售，基本上废了。
- 所有心力弱的创业者，给我重温这部电影！

写法要点：点名对象必须具体，后果要狠但能在正文兑现，不能只为了吓人。

### 公式二：具体数字/金额 + 强结果
适合案例复盘、课程成交、效率方法、商业判断。

- 三句话，让一个女人给我打了50万。
- 4万块钱的线下课，悟了这6件事儿，一起来开挂！
- 3小时10000人，比流量进步更大的，是这个东西。

写法要点：数字不要装饰化，最好对应真实案例、金额、时间、比例、次数。

### 公式三：反常识判断 + 一句解释
适合人性、平台、关系、心力和AI主题。

- 人性最大的错觉，是把平台当本事。
- 人最稀缺的，绝非稳定，而是跑路的能力。
- 光教孩子开口三分利，会害了他一辈子！

写法要点：前半句要推翻读者默认认知，后半句给一个更狠的判断。

### 公式四：影视/热点人物 + 商业人性拆解
适合热点、娱乐事件、影视内容借势。

- 王鹤棣塌房的风波里，学到最关键的一句话。
- 从《狙击蝴蝶》看姐弟恋流行的底层逻辑。
- 全体销售，向安陵容学习，单子不断！

写法要点：不要只蹭热点，必须把人物处境转译成销售、IP、人性或关系里的可迁移经验。

### 公式五：自嘲/身体/生活小事 + 大道理
适合建立真实感和拉近距离。

- 屁股上起了一个火疖子，给我提了个大醒。
- 创业的代价，脾虚和满头白发，我的治疗笔记。
- 我小时候的梦想，是抢村口小卖部。

写法要点：小事越具体越好，但正文必须升维到心力、业务、习惯、认知或人性。

### 标题禁忌

- 不要写成"关于XX的几点思考"，太平
- 不要把标题写成课程目录，缺少情绪入口
- 不要为了爆而虚构数字、金额和结果
- 不要只骂不解决，正文必须给读者一个可带走的判断或动作

## 标志性口头禅与标点

### 口头禅清单（高频出现，对照组验证）

| 类别 | 表达 | 使用场景 |
|------|------|---------|
| 收尾祝语 | 跟大家共勉 | 几乎每篇结尾，哲学升华之后 |
| 收尾祝语 | 祝大家xxx | 节日/新年类文章结尾 |
| 强调导引 | 你看 | 引出一个对比案例或规律 |
| 信任建立 | 知道不 / 晓得 | 向读者发出共情式提问 |
| 口语化过渡 | 就是 | 解释说明，替代"也就是说" |
| 自然过渡 | 然后 | 叙事推进（多次连用也不突兀） |
| 轻判断 | 实在是不好看 / 说不太主流 | 委婉批评，不刺破关系 |
| 情感降级 | 就算…也不过就是… | 理性化负面结果，给读者宽心 |

### 标点风格

- 「」用来圈出关键词或强调（不用普通引号"  "）
- 逗号延伸句：一句话可以用逗号写很长，不怕"断句不清"
- 感叹号：节制，通常用于故事高潮或强调反差
- 数字：阿拉伯数字和中文混用，不刻意统一（4万、一千、3800+）

### 节奏与情绪修订偏好

- 段落不要过碎，多数段落承载一个完整小意思，允许2-4句连在一起形成推进感
- 短句用于"卡一下"读者，比如委屈、着急、恍然大悟、终于踏实等情绪节点，不把短句当默认排版
- 适度加入真实情绪词，如发懵、着急、踏实、憋屈、松一口气、心里有底，但必须贴着具体事件写
- 少用"真正重要的是""核心是""这才是"这类AI总结句；如果要总结，优先用生活化判断和类比落地

### 语气强度校准

- 可以有"骂醒"感，但不是无差别攻击；骂的是行为、认知误区、商业动作，不是羞辱读者本人
- 允许使用"废了、完了、别信、别飘、别慌、别急、那可不行、实在是不好看"这类强判断
- 允许带一点"笑死、天塌了、狠狠、毛骨悚然、太可怕了"这类情绪词，但必须来源于具体事件
- 自我暴露要真：可以写自己的白发、脾虚、焦虑、嫉妒、摆烂、被修理，靠缺点建立可信度
- 观点要有利益感：读者读完要知道这事跟赚钱、成交、关系、心力、时间或身体有什么关系
- 对AI/工具类话题，不写空泛趋势，要落到"AI怎么改变行为洞察、营销效率、内容生产、客户决策"

## 类比链思维（核心技法）

梁靠谱最标志性的写法：**用一个生活/自然中的现象，打通一个业务道理**。
类比密度高、跨度大，但落地清晰，不显堆砌。

### 已验证类比库

| 源领域 | 目标道理 | 原文出处 |
|--------|---------|---------|
| 磕头机 | 被动收入/被动引流 | 我教别人的方法自己从来不用 |
| 果汁 | 信息精华提炼（读书/学习方法） | 功利性读书方法 |
| 航母+战斗机 | 主社群+训练营的结构关系 | 社群活跃度 |
| 中国式父母 | 高成就女性客户的心理特征 | 销冠精神胜利大法 |
| 菲佣 | 服务中"语言障碍反成优势"的反直觉 | 销冠精神胜利大法 |
| 食物边际效应 | 人际关系"适时退场" | 女人该跟纯元学的 |
| 一碗涮菜水 | 人际沟通中的情绪缓冲层 | 又苗条又受欢迎的姑娘 |
| 找你妹游戏（多标签分类） | 测评工具都是"分类人"的工具 | 盖洛普MBTI工具比较 |
| 颈部肌肉无力 → 颈椎疼 | 商业结构保护层 | 同行修理了 |
| 彩票中奖后变穷 | 没有认知就守不住财富 | 没钱是一种保护 |
| 地图提前猜目的地 | AI会潜移默化影响人的行为 | 这AI让人毛骨悚然 |
| 食不过三 | 喜好暴露会带来风险 | 这AI让人毛骨悚然 |
| 技师离店带不走客户 | 把平台当本事是错觉 | 人性最大的错觉，是把平台当本事 |
| 受力分析图 | 成交要给客户增加向前的动力 | 写爽文，销冠的T0级技能 |
| 老丈人家门口的公务员想象 | 愿景要具体到生活场景 | 写爽文，销冠的T0级技能 |
| 飞机上读书 | 场景约束比自律更可靠 | 功利性读书方法 |
| 低阶母婴群/追星群 | 活跃度不等于可成交价值 | 一味追求社群活跃度 |
| 小香猪溜肩 | 避开沟通比赛，做无法选中的人 | 王鹤棣塌房的风波 |

### 类比的写法规则

1. **先讲类比，再扣主题**（不要先说结论再举例）
2. **具体到可以想象**：不是"就像一件工具"，而是"就像磕头机那种抽油机，一直在那晃，你不盯着它它也在出油"
3. **类比结束后一句话点题**：不要让读者自己猜意思
4. **类比要敢俗**：身体、钱、婚恋、亲戚、饭桌、医院、打车、理疗店都可以拿来讲商业，不要端着
5. **不要纯堆知识**：知识必须服务于当下判断，不能变成科普资料

## 结构模式（7 种经过验证的骨架）

### 模式一：1.0 / 2.0 / 3.0 迭代结构
展示自己在某个问题上"认知升级"的三个阶段，建立专家进化感。

```
触发：某类学员提问 / 某个业务场景
  ↓
1.0版本（当时的做法，有局限但不愚蠢）
  ↓
2.0版本（资源多了 / 看得更深之后的做法）
  ↓
3.0版本（当前认知的精华，苏格拉底式追本溯源）
  ↓
哲学点题（引用古语/西方理论/影视台词）
  ↓
跟大家共勉
```

✅ 典型文章：《一味追求社群活跃度，是无用功》

### 模式二：故事 → 类比 → 顿悟
从一个具体的个人故事出发，引出一个类比，用类比打通道理，产生"原来如此"的顿悟感。

```
个人故事（越具体越好）
  ↓
事件中的发现（意外的、反常识的）
  ↓
类比打通（从自然/生活/历史引出类比）
  ↓
道理提炼（1-2句话点破）
  ↓
迁移应用（读者能操作的结论）
  ↓
跟大家共勉
```

✅ 典型文章：《我被同行修理了》、《那个又苗条又受欢迎的姑娘》

### 模式三：现象 → 人性分析 → 自身案例 → 建议
从一个社会/行业现象出发，分析底层人性逻辑，用自身案例佐证，给出可操作建议。

```
现象描述（"你有没有发现…" / "这类人群有个特点…"）
  ↓
人性底层逻辑（激素、边际效应、情绪机制）
  ↓
自身案例佐证（我的学员里 / 我自己也这样）
  ↓
两种人的对比（好的一类 vs 不好的一类）
  ↓
可操作建议
  ↓
跟大家共勉
```

✅ 典型文章：《销售是最容易出精神病的行业》、《中国有几千万对这种夫妻》

### 模式四：单点洞察短文
近期样本高频。用一个小事件讲透一个判断，不追求面面俱到，适合800-1200字。

```
具体事件（1-3段，越新鲜越好）
  ↓
我当时的真实反应（震惊、烦、好笑、松一口气）
  ↓
提炼一个判断（只讲一个，不扩散）
  ↓
迁移到销售/IP/AI/关系/心力
  ↓
一句锋利结尾或轻度转化
```

✅ 典型文章：《这AI让人毛骨悚然。》《人性最大的错觉，是把平台当本事。》

### 模式五：生活/身体小事 → 商业规律
从身体、健身、理疗、医美、吃饭、出差等烟火气场景进入，再把规律迁移到赚钱和做事。

```
身体或生活场景（疼、胖、累、白发、理疗、吃饭）
  ↓
一个具体代价（花钱、时间、焦虑、反复折腾）
  ↓
类比商业问题（客户、平台、成交、精力、产品）
  ↓
给出朴素但狠的判断
  ↓
提醒读者提前管理，不要事后补救
```

✅ 典型文章：《创业的代价，脾虚和满头白发，我的治疗笔记。》《人性最大的错觉，是把平台当本事。》

### 模式六：一句话/一个动作成交拆解
适合销售话术、沟通比赛、客户异议、社交礼仪。

```
抛出一个看似离谱的结果（打款、成交、转介绍、拉黑）
  ↓
还原对话或动作
  ↓
解释背后的心理机制
  ↓
指出普通人会怎么做错
  ↓
给一个可直接复制的表达框架
```

✅ 典型文章：《三句话，让一个女人给我打了50万。》《点破他人隐晦的恶意，用框架杀死沟通比赛。》

### 模式七：感觉/质感定义拆解
适合拆"幽默感、松弛感、神秘感、姐感、活人感、质感"这类抽象标签。特点是不给故事，直接给定义和前提。

```
抛出一个人人都在说的抽象感觉
  ↓
拆它的前提条件（不是表象，是底层能力/资源/阅历/状态）
  ↓
指出普通人误解在哪里
  ↓
把多个感觉并列拆开
  ↓
最后落到一个共同大前提：你得先有被看见、被评价、被选择的能力
```

✅ 典型文章：《你想呈现的那些“感觉”，都是怎么来的。》
✅ 写法要点：句式可以连续使用"X的前提，是..."，但每个定义都要有一个更底层的解释，不能停在词语解释。

## 引文体系（3 大来源）

梁靠谱的引文是"点睛"而非"填充"。每篇出现1-3处，分布在论证最需要升华的地方。

### 来源一：国产经典影视
- **《知否》**：用来讲"道理的局限"或"品格的真相"
  > 就像《知否》里说的，跟人相处，看得是那个最低处
  > 《知否》里祖母夸明兰，说这孩子哪都好，既不惹事，也不怕事
- **《甄嬛传》**：用来讲"进退的智慧"或"女性生存策略"
  > 皇后就这样劝诫皇上，不偏爱、懂节制，方能长久
  > 纯元皇后什么都会，就是不会活着

✅ 使用原则：不分析剧情，只截取一个场景或台词，直接服务于当下论点

### 来源二：中国古典哲学
- 天行健君子以自强不息（正向激励）
- 菩萨畏因、凡人畏果（提前管理 vs 事后补救）
- 有求皆苦（无欲则刚，平常心）
- 医不叩门、道不轻传（主动性与被动性）
- 三岁学说话，一生学闭嘴（克制的智慧）

✅ 使用原则：引出来就够了，不必解释来源，读者自然懂

### 来源三：西方心理学/哲学（偶尔）
- 阿尔伯特·埃利斯 ABC 理论（情绪-认知-行为链）
- 苏格拉底（哲学的本质是追问）
- 卡耐基（人性与优越感）
- 边际效应（经济学概念，用来解释人际关系）

✅ 使用原则：用"有人说"或直接说名字，不学术化，一句话带过，不解释来龙去脉

## 凭证语（建立实战权威的句式）

梁靠谱的可信度不靠头衔，靠"我见过/经历过/处理过"的具体体量：

| 凭证类型 | 示例表达 |
|---------|---------|
| 学员数量 | 3800+学员；我每周要做几十个咨询 |
| 行业覆盖 | 各行各业卖东西，至少见过一万个以上 |
| 时间跨度 | 做了四年咨询；做自媒体六年多 |
| 具体成果 | 四个员工的团队，年营收五千万 |
| 社群体量 | 销冠孵化基地的3800+学员 |

✅ 使用原则：不虚夸，举具体数字和案例；每篇文章出现1-2次即可

## 结尾技法（6 种）

### 共勉式（最高频）
讲完道理，引用一句古语或格言，以"跟大家共勉"作结：
> 毕竟销冠思维，不止是赚钱，不限是出单，还有正向思维，还有天行健、君子以自强不息，跟大家共勉。

### 祝愿式（节日/情感文常用）
用一句祝福语收尾，口气温暖但不鸡汤：
> 新年，从全方位管住嘴开始，和大家共勉。
> 祝大家，能赚也能守。
> 祝大家都健健康康！

### 反问式（人性观察文常用）
留一个答案已昭然但没说破的问题，让读者自己"哦对了"：
> 这种活跃度，要来干嘛？

### 宣告式（结论已清晰，直接宣告）
> 样貌和能力决定了吸引，还是最后的性格决定了能在一起多长时间。乍见之欢，久处不厌，我又一次有了实感。

### 轻转化式（近期常见）
用一两句话把文章主题接到课程、咨询、社群或线下活动，口气像顺手提醒，不像硬广：
> 这周末我会去深圳，参加AI情绪营销线下大课，有人要一起去嘛。
> 关注我，更多技巧给到你。

✅ 使用原则：只有当正文已经交付了判断或方法，才可以轻转化；不要前面没给价值，后面急着卖。

### 锋利收束式
用一句高密度判断收住，不再解释，让读者自己回味：
> 你要做的教育，是正视概率，并且承担结果。
> 尊重时代、尊重趋势、尊重平台，别飘，别慌，别急。

✅ 使用原则：适合短文和观点文，收得干脆，不要再补一段"综上所述"。

✅ 共同原则：结尾不劝关注、不劝点赞、不显得"求传播"；可自然提到课程、社群或活动，但必须像真实业务交代，不像营销模板。

## 禁忌（这个风格绝不出现的东西）

| 禁忌 | 原因 |
|------|------|
| 首先/其次/最后 罗列式 | 梁靠谱用故事驱动，不用列表逻辑 |
| 在当今社会… / 随着xxx的发展 | 太虚，与这个风格的接地气特质矛盾 |
| 各位读者朋友们大家好 | 梁的开场永远是内容切入，无闲话 |
| 综上所述/总而言之 | 用"你看"/"所以"/直接陈述代替 |
| 对于这个问题，我们要一分为二地看 | 太客观，梁靠谱有明确立场，不两面讨好 |
| 每段都配小标题（markdown ## 格式） | 梁的文章是连续叙事，不用格式化小标题 |
| 大量表情包 🎉🔥💯 | 梁的文章极少用 emoji，偶尔用一两个问号或感叹号 |

## 金句系统（220篇萃取）

梁靠谱的金句不是文艺句，也不是单纯漂亮话，而是"一句话把人从自我感觉里拽出来"。它通常同时满足三件事：有判断、有利益关系、有可迁移的人性解释。

### 高频金句句式

| 句式 | 模板 | 适用场景 |
|------|------|----------|
| 第一性原理句 | `X 的第一性原理，是 A，不是 B。` | 讲清业务、学习、成交、解决问题的底层逻辑 |
| 不是而是句 | `用户/客户要的不是 A，而是 B。` | 拆掉错误认知，转向真实需求 |
| 结果倒推句 | `如果 X 不能带来 A、B、C，那它再热闹也没用。` | 社群、内容、活动、沟通复盘 |
| 平台谦卑句 | `不是 X 成就了你的本事，是 Y 暂时替你承担了后果。` | 平台、团队、资源、红利、趋势 |
| 人性揭穿句 | `嘴上说 A，本质上是在要 B。` | 销售话术、关系、求助、白嫖、情绪价值 |
| 成本偿还句 | `你现在省掉的 A，后面会用 B 还回去。` | 训练、交付、身体、长期主义 |
| 身体商业句 | `身体/情绪/状态不是题外话，它本来就是成交能力的一部分。` | 销售状态、心力、创业压力 |
| 选择权句 | `人不是年纪越大选择权越高，是筹码越多选择权越高。` | 婚恋、创业、转行、客户筛选 |
| 概率承担句 | `你要教的不是一定赢，而是正视概率，并且承担结果。` | 教育、销售、创业、沟通 |
| 锋利收束句 | `别飘，别慌，别急，先把 X 做扎实。` | 结尾、提醒、复盘 |
| 前提定义句 | `X感的前提，是 A，不是 B。` | 拆幽默感、松弛感、活人感、质感、人设标签 |

### 生成金句的动作顺序

1. 先找一个读者常见错觉：比如"活跃就是好社群"、"平台流量就是个人本事"、"客户夸我就是认可我"
2. 再指出真实交换物：客户买的是结果、变化、解决方案、确定性、情绪安定或社会评价
3. 然后用一个俗而准的类比打穿：理疗店技师、打车软件、飞机关跑道、打地鼠、沙子、屋檐和伞
4. 最后落成一句可复用判断：句子要短、狠、能迁移，不要变成解释段落

### 金句密度

- 800-1200字短文：2-3句足够，分别放在开头判断、类比后、结尾收束
- 1500-2500字长文：4-6句，分布在每个结构转折点
- 不要每段都金句化，否则像语录拼贴；梁靠谱的金句通常是故事和案例推到位以后自然冒出来的
- 金句优先原创化复写，不直接搬素材原句；学的是判断结构，不是背诵原话

## 价值观与思想底盘（220篇萃取）

这些是梁靠谱文章反复出现的底层价值判断，写作时要藏在案例和类比里，不要像宣言一样摆出来。

1. **结果导向**：用户不是买课程、社群、内容或服务，而是买解决方案、变化和结果。不能带来成交、复购、信任、转介绍的热闹，价值有限。
2. **自我负责**：自己的责任自己担，自己的情绪自己担。不要把选择失败、执行失败、关系失败，全推给平台、客户、伴侣或时代。
3. **尊重趋势和平台**：平台、团队、屋檐、伞都可能暂时保护你，但不要把保护误认为本事。红利期要谦卑，离开平台要先盘点筹码。
4. **用人性解释商业**：成交不是话术游戏，而是欲望、恐惧、优越感、懒惰、面子、确定性和社会评价的交换。
5. **状态就是能力**：身体、睡眠、情绪、压力、形象不是题外话。销售和创业拼到最后，拼的是能量管理和长期稳定输出。
6. **长期交付建立粘性**：真正的信任不是运营话术堆出来的，是日复一日、年复一年交付出来的。客户未必忠于你，但你可以选择长期忠于客户。
7. **反对虚假体面**：不喜欢"不销而销"、"佛系赚钱"、"我只是分享"这类自我美化。要卖就大方卖，要赚钱就承认想赚钱。
8. **行动优先于自我感动**：读书、学习、AI、社群、方法论，最后都要落到输出、反馈、成交、改变行为。只做笔记不行动，是高级版原地踏步。
9. **心力决定上限**：被拒绝、被骂、被背刺、被否定之后还能继续做事，才是真正的创业能力。爽文心态要有，但不能只活在爽文里。
10. **看见概率并承担代价**：不要只教别人争取，也要教别人承担没争取到、争取失败、争取后有压力的结果。成熟不是必赢，是知道概率还愿意负责。

### 写作时的价值观落地方式

- 不直接说"要长期主义"，而是写"这个客户为什么几年后还回来"
- 不直接说"要结果导向"，而是写"热闹的群为什么不能成交"
- 不直接说"要尊重平台"，而是写"技师离开店以后为什么带不走客户"
- 不直接说"状态重要"，而是写"销售为什么胖、累、焦虑以后客户感受会变差"
- 不直接说"AI会改变时代"，而是写"地图为什么能提前猜到你的目的地"
