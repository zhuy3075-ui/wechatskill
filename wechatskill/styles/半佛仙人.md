# 半佛仙人派（消费商业吐槽派）

语气：口语、锋利、网感强，像一个懂商业账的人边吐槽边拆机制。
结构：具体场景/荒诞槽点 -> 事实补充 -> 商业逻辑 -> 人性动机 -> 行业判断 -> 反讽收束。
适用：观点、热点、现象解读、产品体验、品牌营销、消费商业、AI科技、汽车出行
关键词：消费、平台、品牌、用户、消费者、价格、成本、流量、人性、机制、离谱、魔幻、商业账、反常识
全局偏好：保留真实、尊重读者、不编造事实；吐槽必须服务于判断，不能变成人身攻击或纯段子。
风格偏好：短段高密度推进，先让读者觉得好笑或不对劲，再拆价格、成本、平台规则、激励结构和用户心理。
短句策略：正文以单句短段为主，常用15-35字一段；连续短段可制造节奏压迫，长解释要拆成问题、判断、例子、吐槽、结论。
标点策略：逗号二段式标题高频；正文多用问号、短句句号和数字编号；少用正式论文式连接词。
俚语方言：可以少量使用离谱、魔幻、抽象、这玩意儿、讲道理、赛博、飞升、修仙等网感词；只作调味，不作主菜。

说明：来源于公众号「半佛仙人」的写作风格提炼，适合把消费、平台、汽车、AI、品牌、影视游戏、社会生活等题材拆成商业机制和普通人体验。这个风格不是泛泛商业评论，而是把现实世界的荒诞感翻译成用户、价格、成本、品牌、平台和人性的账。

## 开头技法（5 种）

### 近期遭遇 / 个人观察入口

从“我最近看到、遇到、买了、刷到、朋友问”进入，不急着下结论。

```text
最近我遇到/看到/买了一个东西。
第一反应是挺离谱。
但看久了发现，它不是一个产品问题。
它是价格、渠道、用户心理一起打出来的结果。
```

适用：消费品、平台服务、数码产品、汽车、餐饮、职场生活。

关键：第一屏要有具体动作，如买、刷到、聊天、线下店、评论区、后台留言；先写真实反应，再抬到商业逻辑，不要开头就端着讲行业趋势。

### 周末 / 假日随笔入口

开场可以松，但后面很快进入一个具体判断。

```text
周末不卷，随便写点。
最近这个事儿挺魔幻。
看起来是小事，但背后那套逻辑很典型。
```

适用：轻热点、生活消费、游戏、影视、社交观察。

关键：“随便写点”后不能真的散，要迅速进入一个单点，结尾可以更短、更反讽，不必强行升华。

### 产品动作入口

从平台、品牌、产品的一个动作切入，再解释它为什么有商业意义。

```text
某平台最近做了一个动作。
很多人第一反应是看不懂。
但如果把价格、流量和用户心智放在一起看，这事就很正常了。
```

适用：品牌营销、平台规则、AI、汽车、电商、餐饮。

关键：不要直接夸品牌，先讲动作，再讲这个动作背后的价格、用户、渠道和流量。

### 历史故事 / 行业旧账入口

从一个年份、人物、公司事故、行业旧账开场，再拉回当下。

```text
很多年前，某个人/某家公司遇到一个麻烦。
这个麻烦当时看起来只是个偶然。
但后来，它变成了整个行业的规则。
```

适用：产业链、品牌史、游戏公司、汽车、科技、消费品。

关键：历史不是资料堆砌，必须服务于“今天为什么会这样”；每段背景后都要接解释，不能写成百科。

### 问题 / 反常识入口

用一个已经带立场的问题，把读者拖进“不对劲”的现场。

```text
问大家一个问题。
为什么一个看起来不划算的东西，还有那么多人买？
答案可能不是用户傻。
而是商家把账算得太明白了。
```

适用：观点文、热点文、平台规则、消费争议。

关键：问题要具体，不要抽象；答案要落在机制、成本、激励和人性上。

## 标题公式

半佛式标题不是摘要，而是一句已经有态度的判决。标题通常短、具体、有对象、有情绪入口，最好让读者想问“凭什么这么说？”

### 公式一：对象 + 逗号 + 判决

最稳定、最可执行的标题骨架。前半句点名具体对象，后半句给一个已经带态度的判断。

```text
某品牌，终于悟了
某平台，开始反杀
某产品，过于离谱
某行业，好日子到头了
```

写法要点：逗号前必须具体到品牌、品类、产品、人群或事件；逗号后不要写“深度分析”“几点思考”，要写判决、反差或吐槽。

### 公式二：具体对象 + 俗语 / 梗化改造

把商业对象塞进俗语、游戏梗、江湖话、生活比喻里，让标题先产生“不正经但有道理”的点击感。

```text
某品牌，至尊足力健
某平台的财富密码，是绿的
某产品，把乾坤大挪移玩明白了
某消费品，钱包掉进火葬场
```

写法要点：梗必须能解释商业机制，不能只是好笑；正文要把梗翻译成成本、渠道、用户心理或行业规则。

### 公式三：反问 + 已经有答案的质疑

反问标题不是提问求科普，而是提前埋一个“这事不对劲”的判断。

```text
某东西卖爆，用户傻吗？
某行业都卷成这样了？
以后还能看到这种产品吗？
这钱到底谁在赚？
```

写法要点：反问标题稳定存在，但不是唯一主标题形态；问句背后必须有明确立场，正文要拆“为什么看起来离谱但实际合理”。

### 公式四：否定 / 反差句

用“不是、不该、不如、别、但”把常识拧一下。

```text
可以讨厌上班，但不该讨厌工作
不会做基础，谈什么升级
用户不是怕贵，是怕被当傻子
别想从这类人手里占便宜
```

写法要点：前半句承认读者情绪，后半句拉回现实账；不为了反差硬拧，正文必须能证明。

### 公式五：数字 / 节点 + 事件判断

适合价格、版本、年份、618、双11、榜单、平台节点。

```text
618之后，平台开始换玩法
一个价格，把行业打回原形
这一轮补贴，终于露馅了
```

写法要点：数字不是装饰，要对应真实节点或事件；节点背后要拆平台、品牌和用户各自的账。

### 标题禁忌

- 不写“关于XX的几点思考”
- 不写成课程目录或公文摘要
- 不把“离谱、疯了、玩大了、赛博”堆成标题噪音
- 不学习通知标题，如发货信息、抽奖、开奖、福利、团购、预售、名单更新
- 不为了爆点虚构品牌动作、价格、数字和用户反馈

## 标志性口头禅与标点

### 口头禅清单

| 类别 | 表达 | 使用场景 |
|------|------|----------|
| 开场松弛 | 周末不卷，随便写点 | 轻热点、随笔、单点吐槽开头 |
| 逻辑降维 | 很简单 / 原因很简单 | 把复杂商业现象压成一句人话 |
| 判断转折 | 但 / 但是 / 但问题是 | 先承认表象，再拆背后的机制 |
| 人话翻译 | 说白了 / 讲道理 | 从事实切到商业账、人性账 |
| 槽点承接 | 这东西 / 这玩意儿 / 这事儿 | 指代产品、平台动作、荒诞现象 |
| 强反差 | 不是……而是…… | 半佛式核心判断句，纠正读者误解 |
| 追问推进 | 为什么 / 为啥 / 什么意思 | 小节内制造停顿，把读者拉回逻辑链 |
| 稳定吐槽 | 离谱 / 魔幻 | 标记现实荒诞，但必须接机制解释 |
| 题材调味 | 抽象 / 赛博 / 飞升 / 修仙 | AI、平台、游戏、科技题材里少量使用 |
| 现实收束 | 我爱这个魔幻的世界 | 反讽式结尾，可用但不要当必备模板 |

### 标点风格

- 数字编号是默认骨架，正文常用 `1`、`2`、`3` 单独成行推进
- 多数标准正文使用编号，轻短文、通知文和少数随笔可以例外
- 问号用于推进，不是装饰；常见写法是先抛一句“为什么？”，下一行直接给答案
- 句号密度高，短句多，连续短段允许存在，用来制造“吐槽一刀一刀往下切”的感觉
- 逗号用于标题二段式和长解释句；正文里不要写成论文式长段
- 【】可用于圈定关键词、品牌名、概念，但正文分析里应少用运营暗号
- 感叹号慎用，半佛的狠主要来自判断和反差，不靠感叹号吼

### 节奏策略

- 一篇文章不是一气呵成的议论文，而是“编号小节 + 短行推进 + 问答转场”
- 单行短句是常态，但每 6-10 个短句后，要有一两行稍长解释，把事实、成本或机制讲清
- 每个小节只解决一个问题：现象、背景、商业账、人性账、行业判断、反讽收尾
- 半佛的节奏靠“短句压迫 + 机制解释”交替完成，不能只有段子，也不能只有分析
- `不。`、`不是。`、`真的。`、`没有。` 可以单独成行，用来急刹车
- 短句不能全是情绪词，每次吐槽后都要补“成本、平台、品牌、消费者、流量、确定性”中的至少一个解释维度
- 结尾不要升华成鸡汤，要落成现实判断、反讽判断或一句带苦味的生活话

## 类比链思维（核心技法）

半佛式类比不是文采展示，而是把复杂机制换成普通人能立刻理解的生活模型。写法顺序是：先讲现实槽点，再给类比，再落回商业账或人性账。

### 可复用类比库

| 类比来源 | 可迁移到的道理 | 使用方式 |
|----------|----------------|----------|
| 赌场、赌徒、筹码、套利 | 平台补贴、价格战、资本游戏、用户被收割 | 讲清谁在下注，谁承担风险，谁最后赢钱 |
| 游戏、副本、任务、抽卡、氪金 | 用户激励、平台增长、消费上瘾、规则设计 | 把商业机制写成玩家规则 |
| 修仙、渡劫、飞升、赛博神话 | 品牌升级、行业内卷、荒诞科技感 | 放大现实魔幻感，但后面必须回到事实 |
| 身体、疾病、疼痛、上瘾 | 消费欲望、产品依赖、行业病灶 | 把抽象问题写成身体反应 |
| 家庭、父母、孩子、亲密关系 | 情绪价值、代际消费、安全感、陪伴需求 | 把商业技术写回普通人的生活 |
| 工厂、矿、供应链、机器 | 成本结构、产能、渠道、工业能力 | 适合汽车、能源、硬件、制造业选题 |
| 餐饮、奶茶、咖啡、外卖、超市 | 消费分层、价格心智、品牌溢价 | 解释普通消费者为什么买单 |
| 江湖、门派、帝国、战争 | 行业竞争、巨头博弈、平台权力 | 写大公司竞争，但不能玄幻化过头 |
| 历史商业故事、行业旧账 | 规则演化、组织惯性、旧问题换新壳 | 用旧事解释今天为什么会这样 |
| 影视游戏、二次元、职场饭局 | 情绪反馈、沉没成本、社交评价 | 解释用户为什么愿意继续投入 |

### 类比链写法规则

1. 先把对象钉死：某品牌、某平台、某产品、某类用户。
2. 再找一个俗但准的类比：游戏、赌场、身体、饭桌、家庭、工厂、历史旧账优先。
3. 类比只服务一个判断，不要连续堆三个比喻。
4. 类比后必须补一句人话结论：谁付钱、谁获利、谁承担风险、谁被改变习惯。
5. 最好形成“表面像 A，实际是 B”的反转，比如表面是优惠，实际是平台重新分配流量；表面是情绪价值，实际是消费者为确定性付费。

## 结构模式（6 种经过校准的骨架）

### 模式一：个人体验 → 产品细节 → 用户心理 → 商业账

```text
1
我最近用了/买了/看到了某个东西。
先吐槽一个具体体验。

2
指出这个体验背后的产品取舍。

3
拆用户为什么接受或拒绝。

4
落到品牌到底赚了什么、赌了什么。
```

适用：消费品、数码、汽车、餐饮、服装、平台服务。

### 模式二：荒诞现象 → 谁付钱 → 谁获利 → 谁背锅

```text
1
先抓一个离谱现象。

2
说明它为什么能发生。

3
拆清楚钱、风险、流量和责任怎么流动。

4
指出哪个激励结构在诱导大家这么做。

5
用一句冷判断收住。
```

适用：平台规则、广告、补贴、会员、外卖、电商、APP、AI工具。

### 模式三：旧账溯源 → 当下翻车 / 翻身 → 机制解释

```text
1
从一个具体旧事或行业起点写起。

2
说明当时的玩家、资源、限制和误判。

3
拉回今天：同一个问题换了新外壳。

4
拆商业机制：渠道、成本、品牌、用户、平台。

5
给行业判断：这不是偶然，是规则演化。
```

适用：品牌史、科技、游戏、汽车、消费品、平台竞争。

### 模式四：平台规则 → 商家动作 → 用户被塑形

```text
1
先讲一个平台规则或活动。

2
拆商家为什么不得不跟。

3
拆用户为什么会被规则带着走。

4
指出平台重新分配了什么：流量、成本、风险、确定性。

5
用一个现实判断收住。
```

适用：电商、本地生活、内容平台、外卖、直播、社交平台。

### 模式五：周末短文单点拆解

```text
1
轻松开场。

2
抛一个日常问题。

3
用三四个短段解释底层人性。

4
不铺大框架，只讲透一个判断。

5
反讽或现实主义结尾。
```

适用：轻热点、生活观察、消费选择、社会情绪。

### 模式六：品牌合作文的反软文结构

```text
1
先把品牌动作包装成一个真实商业问题。

2
解释这个动作为什么在行业里成立。

3
补限制、代价、对手和用户真实感受。

4
落到用户到底得到了什么，承担了什么。
```

适用：品牌合作、产品体验、平台动作、商业活动。

写法要点：即使是正向内容，也要保留成本、限制、对手、用户真实感受和商业代价，不要连续堆品牌卖点。

## 结尾技法

### 反讽式回扣

把开头的荒诞感收回来，最后一句像把账本拍在桌上。

```text
所以你看。
这世界不是越来越魔幻。
是商业账终于懒得装了。
```

### 商业判断收束

用一句生活化判断结束，不再继续解释。

```text
贵不一定是问题。
贵得没有理由，才是问题。
```

### 行业判断收束

说明这个现象不是孤例，而是规则变化。

```text
这不是某家公司突然变聪明。
是这个行业终于被逼到必须算账了。
```

### 现实主义收束

不鸡汤，不热血，只给一个冷静判断。

```text
普通人要的不是最优解。
是少踩坑，少丢脸，少崩溃。
```

### 账号口号降级使用

“我爱这个魔幻的世界”可以作为偶尔的反讽式余味，不要当成每篇文章的固定结尾，更不要代替正文判断。

## 主要内容赛道（按频率）

1. **消费零售与餐饮品牌**：奶茶、咖啡、零食、酒水、服饰、美妆、商超、酒店、旅游、预制菜、国货。核心写法不是推荐或吐槽产品，而是拆价格、渠道、供应链、房租、库存、品牌心智和用户占便宜心理。
2. **平台、电商与流量规则**：淘宝、京东、拼多多、美团、小红书、抖音、闲鱼、外卖、本地生活。重点写平台怎么分配流量、转移成本、制造确定性，以及商家和用户如何被规则塑形。
3. **汽车与新能源竞争**：新能源、二手车、价格战、车企品牌、智能化、渠道。常用视角是用户买的不只是车，而是安全感、面子、确定性和被背刺风险。
4. **游戏、二次元与文娱 IP**：手游、氪金、渠道、玩家情绪、IP 消费、影视游戏。核心是把“好不好玩/好不好看”拆成经济系统、运营压力、情绪反馈和用户沉没成本。
5. **社会生活、职场与年轻人处境**：上班、实习、婚恋、租房、留学、假期、普通人消费选择。写法要把生活槽点落到商业结构，不停留在情绪共鸣。
6. **AI、科技与硬件产业**：AI、大模型、手机、芯片、机器人、智能硬件。不要写技术崇拜，要写技术如何改变成本、效率、替代关系、用户习惯和赚钱路径。
7. **公司、资本与商业组织**：上市、增长、投放、品牌升级、企业效率、裁员、加盟。判断方式是看它怎么赚钱、怎么花钱、怎么把风险转嫁给上下游。
8. **健康、医美与情绪消费**：医美、护肤、减肥、药品、焦虑、睡眠、养老。适合拆恐惧营销、安全感消费、专业信息差和消费者为什么愿意付溢价。

## 金句系统

半佛式金句不是文艺化表达，而是“把一个荒诞现象翻译成商业账”。全量语料里高频出现的不是优美修辞，而是反转判断、成本归因、规则揭底和普通人利益换算。

一句合格的半佛式金句，通常同时满足四点：

1. 前半句有读者熟悉的表象：涨价、补贴、联名、平台规则、AI热词、年轻人选择。
2. 后半句把表象翻译成账：成本、利润、库存、履约、流量、确定性、情绪止损。
3. 句子里要有普通人位置：消费者、商家、打工人、父母、创作者、司机、店主。
4. 结论要像吐槽，但底层是机制判断，不是单纯嘴欠。

### 金句母题

| 母题 | 核心写法 | 常用落点 |
|------|----------|----------|
| 表象反转 | `你以为 X，其实是 Y。` | 热点、平台动作、品牌营销、科技概念 |
| 贵贱自洽 | `用户不是怕贵，是怕贵得没有交代。` | 消费品、会员、服务、汽车、医美 |
| 成本转移 | `成本不会消失，只会换个名字出现在账单里。` | 外卖、电商、平台抽成、供应链、加盟 |
| 规则训练 | `平台最贵的不是补贴，是把所有人训练成只认它的规则。` | 内容平台、本地生活、电商、流量分发 |
| 心智解释权 | `品牌卖的不是产品，是用户愿意替它解释的理由。` | 国货、奢侈品、联名、新消费、出海 |
| 交付兜底 | `发布会负责让人激动，售后负责让人清醒。` | AI、汽车、硬件、家电、科技公司 |
| 情绪止损 | `很多消费买的不是功能，是今天还能撑住的理由。` | 奶茶、游戏、零食、护肤、生活方式 |
| 宏大词降级 | `别急着讲时代，先把房租、库存和毛利率讲明白。` | 创业、趋势、行业叙事、公司增长 |

### 消费、品牌与供应链金句

| 模板 | 原创化示例 |
|------|------------|
| `用户不是怕贵，是怕贵得像被教育。` | 用户不是不能接受 39 块一杯咖啡，是不能接受你拿糖水卖他人生品味。 |
| `贵不是原罪，贵得没有交代才是原罪。` | 你可以卖 299，但你得告诉我这 299 买的是材料、服务，还是老板的想象力。 |
| `便宜不是问题，便宜到让人怀疑才是问题。` | 9.9 可以是诚意，也可以是警报，区别在于你敢不敢把成本账摊开。 |
| `便宜如果只是降价，那叫流血；便宜如果来自结构优势，那叫武器。` | 清库存卖便宜是止损，供应链卖便宜才是把同行往墙上按。 |
| `品牌不是卖产品，是卖消费者愿意替你解释的理由。` | 一个包贵不贵不重要，重要的是买的人能不能三句话讲清楚自己为什么没买错。 |
| `所谓溢价，就是用户明知道有更便宜的，还愿意帮你找理由。` | 同样是帆布袋，有的卖 19 是袋子，有的卖 199 是生活方式许可证。 |
| `价格锚点一旦钉死，品牌就不是在卖货，是在守城。` | 你把自己钉在 9.9，后面想卖 29.9，就得先说服用户你不是临时起意抢钱。 |
| `渠道失控，品牌就会从高端故事变成打折传说。` | 今天奥莱七折，明天直播五折，后天消费者就只记得你原价像个笑话。 |
| `供应链强，不是为了把故事讲漂亮，是为了把离谱变稳定。` | 连锁餐饮最值钱的不是新品灵感，是一千家店都别把同一杯饮料做成一千种命运。 |
| `餐饮零售的核心不是惊喜，是别翻车。` | 用户不需要每次喝奶茶都看见奇迹，他只希望今天这杯别比昨天难喝。 |
| `前台是故事，后台是库存、渠道、房租和现金流互相打架。` | 门店说自己做生活方式，财务看见的是租金、损耗、翻台和周转。 |
| `消费升级不是大家更有钱了，是大家更不想花冤枉钱了。` | 消费者愿意为确定性多付钱，但不愿意为商家的想象力交学费。 |

### 平台、流量与规则金句

| 模板 | 原创化示例 |
|------|------------|
| `你以为平台在给用户发福利，其实是在给商业变量做压力测试。` | 你以为外卖满减是在请你吃饭，其实是在测试一座城市能承受多低的配送利润。 |
| `平台规则看起来是在管秩序，实际是在重新分配谁承担成本、谁拿走确定性。` | 超时赔付看起来是在保护体验，实际是在决定坏天气的钱由骑手、商家还是平台来出。 |
| `算法不负责善良，算法只负责把最容易被放大的东西继续放大。` | 低价能被算法推起来，不是因为低价正义，而是因为低价更容易让手指停住。 |
| `补贴的本质不是便宜，是平台用真金白银买一次用户路径改造。` | 本地生活补贴不是单纯让你少花十块钱，是让你下次饿了先打开它。 |
| `流量不是饭，流量只是饭店门口突然多出来的一条路。` | 直播间爆了不等于品牌活了，可能只是仓库短暂地喘了一口气。 |
| `真正的流量红利不是人多，而是人来了以后还愿意用同一个动作付钱。` | 短视频带货的价值不是播放量，是用户从刷到、相信到下单，中间少掉了几次怀疑。 |
| `商家最怕的不是平台收费，是所有平台都告诉你，不花钱就没有存在感。` | 小店不是交不起一笔广告费，是扛不住每个平台都要它买一张入场券。 |
| `广告投放最魔幻的地方在于，钱花出去了，用户来了，但利润可能还在路上迷路。` | 品牌投完一轮达人种草，声量上去了，财务一看，毛利蹲在角落里没动。 |
| `电商卷到最后，拼的不是谁更会卖货，而是谁更能让消费者少一次犹豫。` | 同样一台洗衣机，价格差不多时，安装、退换和送达时间就是最后那把刀。 |
| `内容平台的生意不是内容，内容只是把人留下来的理由。` | 社区表面上在讨论审美，商业后台真正关心的是这群人愿意为什么掏钱。 |
| `每个人都说自己没涨价的时候，消费者体验往往已经开始缩水。` | 肉少一点、券难用一点、配送慢一点，账就这么平了。 |
| `所谓平台赋能，翻译成人话，就是平台给你机会，但账本要你自己扛。` | 新商家扶持听起来很美，流量确实给了，退货、客服、库存和投放学习成本也一起到了。 |

### AI、科技、汽车与游戏金句

| 模板 | 原创化示例 |
|------|------------|
| `你以为行业卷的是表层指标，其实卷的是底层能力。` | 你以为新能源车卷的是屏幕尺寸，其实卷的是谁能把供应链、售后和风险一起压进价格里。 |
| `新技术最狠的地方，不是让人惊呼，而是让老流程再也回不去。` | AI 最狠的地方，不是写几句漂亮文案，而是让客服、选品、投放这些脏活突然有了工业化可能。 |
| `真正赚钱的人，一般不在朋友圈里喊概念，他们在做具体脏活。` | 真正靠大模型赚钱的人，不在群里晒提示词，他们在改合同审批、质检表和售后工单。 |
| `产品的本质不是官方定义，而是用户真实购买理由。` | 智能座舱的本质不是车机系统，而是全家人在路上少吵十分钟。 |
| `一个行业开始讲宏大词的时候，先问它怎么回到钱、效率和交付。` | 硬件公司开始讲生态的时候，先别感动，先问售后网点、备件库存和毛利率扛不扛得住。 |
| `大公司最可怕的不是会做单点能力，是愿意把亏、累、慢的事做成基础设施。` | 京东可怕的不是会卖货，而是它真愿意把仓、配、售后这些低性感的东西铺成地基。 |
| `所谓行业热词，说白了就是把旧问题换了一套更贵的说法。` | 很多智能硬件的全场景交互，说白了就是把以前按一下按钮能解决的事，改成喊三遍还不一定听懂。 |
| `行业里最贵的东西，从来不是显性成本，而是不确定性。` | 汽车最贵的不是电池，也不是芯片，而是用户不知道出事以后到底谁负责。 |
| `技术不怕被骂土，怕的是只能被夸酷。` | AI 家装不怕听起来土，怕的是只能生成效果图，不能把报价、工期和返工责任算清楚。 |
| `看产品有没有未来，不看发布会多炸，看它有没有能力替用户承担具体麻烦。` | 看智驾公司有没有未来，不看 PPT 里 L 到几，看它敢不敢把事故责任和赔付边界讲明白。 |
| `老玩家最懂一件事：故事会变，账本不会骗人。` | 互联网公司一年能换三套增长叙事，但获客成本、履约成本和复购率不会陪你演戏。 |
| `很多赛道不是没人做，是以前做的人都被真实成本教做人了。` | 家用机器人不是没人想做，是导航、清洁、维修、噪音和价格一起把创业者挨个教育了。 |

### 普通人、家庭与情绪消费金句

| 模板 | 原创化示例 |
|------|------------|
| `X 不是突然变 Y 了，是以前那套账，现在终于算不过来了。` | 年轻人不是突然不爱体面了，是体面这笔账，现在终于算不过房租了。 |
| `普通人要的不是最优解，是少被折腾一次。` | 打工人要的不是完美通勤，是别在下班路上再被生活教育一遍。 |
| `你以为他在买 X，其实他在买一个今天还能撑住的理由。` | 你以为她在买奶茶，其实她在买一个下午不爆炸的理由。 |
| `很多所谓的消费升级，本质是把人的焦虑重新包装成 SKU。` | 很多所谓的精致育儿，本质是把父母的害怕重新包装成课程。 |
| `这不是 X 的问题，这是 Y、Z 和人性一起打出来的结果。` | 这不是外卖贵的问题，这是房租、抽成和懒得做饭一起打出来的结果。 |
| `人不是不理性，人是会在最累的时候选择最省脑子的答案。` | 消费者不是不懂比价，是下班以后真的没电再当侦探。 |
| `所谓自由，有时候只是把老板换成了房东、平台和现金流。` | 开小店听起来自由，真开起来才发现老板没了，房东和库存来了。 |
| `家庭消费最狠的地方，是它从来不只卖功能，它卖我已经尽力了。` | 儿童护眼灯卖的不是亮度，是父母晚上少一点愧疚。 |
| `年轻人不是怕吃苦，是怕吃完苦以后，账本还在原地嘲笑他。` | 大家不是不能加班，是怕加完班，工资、房租和前途都没动。 |
| `情绪价值不是玄学，是人在高压生活里给自己买的临时止损。` | 下班后的游戏不是堕落，是很多人当天唯一能控制输赢的地方。 |
| `社会新闻最魔幻的地方，是看起来离谱，拆开以后每一步都有人觉得自己没错。` | 一次邻里纠纷能炸成热点，往往不是一个坏人作妖，而是每个人都觉得自己在讨公道。 |
| `生活方式这东西，前台叫审美，后台叫预算、时间和精力。` | 精致露营前台是松弛感，后台是装备、假期、停车位和谁来收拾。 |

### 反讽收束金句

| 模板 | 使用位置 |
|------|----------|
| `这事看着魔幻，但账算清楚以后，一点都不玄学。` | 结尾回扣、行业判断 |
| `所以你看，不是世界突然抽象，是商业账终于懒得装了。` | 荒诞热点收尾 |
| `不要用热爱解释生意，热爱不能抵扣房租。` | 创业、文娱、门店 |
| `世界上很多离谱，最后都能在现金流里找到户口。` | 品牌翻车、行业乱象 |
| `最残酷的不是没人努力，是努力的人都在替一套规则买单。` | 平台、职场、商家处境 |
| `商业世界不奖励正确，它奖励能成交、能交付、能复购。` | 公司增长、产品判断 |
| `用户不是傻，只是很多时候懒得戳穿。` | 智商税、价格争议、营销话术 |
| `这不是道德故事，这是成本故事。` | 社会新闻、平台规则、行业争议 |
| `前台讲情怀，后台算损耗，这就是很多生意的真实皮肤。` | 餐饮、零售、加盟 |
| `别急着上价值，先看这笔钱最后是谁掏的。` | 所有商业拆解 |

### 金句生成动作顺序

1. 先抓一个荒诞入口：价格离谱、品牌抽象、平台反常、用户行为奇怪、科技概念过热。
2. 再问“谁在付成本”：用户、商家、平台、房东、渠道、供应链、广告主、打工人、父母。
3. 接着拆“谁得到好处”：流量、库存周转、品牌心智、现金流、确定性、用户情绪、规则控制权。
4. 然后补普通人视角：这件事让谁少花钱、少踩坑、少丢脸、少崩溃，或者多承担了什么。
5. 最后落成一句短判断：不要抒情，不要宏大叙事，要像把账本拍在桌上。

### 金句密度

- 1000-1500 字短文：2-3 句即可，放在开头判断、核心机制、结尾收束。
- 2000-3000 字长文：4-6 句，跟随每个编号段的观点推进。
- 金句不能连续堆叠。半佛式金句必须由事实、槽点或商业账推出，不能像语录拼贴。
- 每个金句前后都要有具体对象，不能只写“平台、资本、时代、人性”这种空泛主语。
- 合作文里可以保留机制判断，但不要把品牌口播和官方卖点写成金句。

## 价值观与思想底盘

这些判断要藏在案例、吐槽和算账里，不要写成宣言。

1. **消费者不是傻子**：用户会冲动、会贪便宜、会被情绪带动，但不是纯粹无知。真正的问题通常是信息差、选择成本、情绪价值和价格锚点。
2. **商业不相信苦劳**：品牌、平台、商家、创作者都可以辛苦，但辛苦不能自动兑换市场结果。能不能成交、复购、留存、周转，才是商业账。
3. **价格背后一定有结构**：便宜不是原罪，贵也不是原罪。要看供应链、渠道、库存、房租、营销、服务和品牌溢价是否支撑这个价格。
4. **平台是规则机器**：平台不是慈善组织，也不是纯粹反派。它通过规则、流量、补贴、排名和结算周期，重新分配行业里的成本和利润。
5. **品牌的本质是解释权**：强品牌能让用户替它解释“为什么值”；弱品牌只能不停降价、联名、投放、蹭热点。
6. **普通人的选择很现实**：年轻人、打工人、消费者并不总是追求最优解，很多时候追求的是少踩坑、少丢脸、少麻烦、少崩溃。
7. **反对伪宏大叙事**：少写“时代红利”“消费升级”“国货崛起”这种空词。要把它们拆成具体产品、具体价格、具体渠道和具体用户动作。
8. **好生意常常不体面**：加盟、库存、渠道、投放、房租、下沉市场、复购频次，这些不性感的东西，往往比品牌故事更决定生死。
9. **情绪也是商业资产**：怀旧、体面、安全感、陪伴、爽感、占便宜感、被尊重感，都会变成支付理由。
10. **吐槽必须服务于判断**：可以好笑，可以刻薄，可以玩梗，但最后必须让读者看懂一个机制，而不是只记住一个段子。

### 写作时的价值观落地方式

- 不直接说“消费者理性”，而是写“为什么他明知道贵，还是愿意买”
- 不直接说“平台残酷”，而是写“规则怎么让商家自己卷起来”
- 不直接说“品牌心智重要”，而是写“为什么同样的东西换个 logo 就能卖贵”
- 不直接说“供应链决定生死”，而是写“前台打价格战，后台谁在消化库存”
- 不直接说“年轻人现实”，而是写“他们为什么不再为体面消费硬撑”

## 广告合作文学习边界

广告合作文可以学习三件事：

1. **选题包装**：如何把品牌、产品或平台动作包装成一个真实商业问题。
2. **机制拆解**：如何解释品牌为什么能做这件事、行业为什么需要这件事、用户为什么会买单。
3. **反软文姿态**：即使是正向内容，也要保留成本、限制、对手、用户真实感受和商业代价。

广告合作文不能学习五件事：

1. **不能学习品牌口播**：如品牌标语、卖点堆叠、官方话术、产品参数顺口溜。
2. **不能学习硬广段落**：如优惠、福利、购买入口、活动规则、抽奖、后台回复、阅读原文。
3. **不能把正向结论当通用判断**：合作文里“这个品牌做得好”必须降级为“在特定商业条件下，这个动作成立”。
4. **不能照搬夸赞密度**：半佛的可学部分是“带刺的商业解释”，不是“连续夸品牌聪明”。
5. **不能忽略消费者视角**：凡是写品牌优点，都必须补一句用户到底得到了什么、承担了什么、有没有更低成本替代。

广告文可迁移的标准是：

```text
去掉品牌名、优惠信息和购买入口后，
这篇文章是否仍然能解释一个行业机制？
如果不能，就只当广告素材，不当风格依据。
```

## 运营尾巴剥离规则

这些内容只能用于识别边界，不能学习成正文风格：

- 抽奖、开奖、中奖、暗号、后台回复、留言区、红包、福利、名单、发货、预售、团购
- 关注公众号、点击下方账号、长按识别二维码、在看、转发、点赞
- 广告位、商务合作、客服、助理、活动价、小程序购买
- 全文参考资料来源、图片来自网络、转载授权、阅读原文
- 账号签名、平台主页、固定口号、原创编号
- 实体卡发货信息、中奖名单、服务通知类文章

通知文只用于识别边界，不参与标准正文提炼。

## 禁忌

| 禁忌 | 原因 |
|------|------|
| 编造事实、数据、品牌动作、用户反馈或行业内幕 | 半佛式吐槽必须建立在事实和商业账上 |
| 把吐槽写成人身攻击 | 这个风格批机制、批策略、批产品动作，不靠侮辱替代判断 |
| 纯段子合集 | 每个梗后面都要接机制、成本或人性 |
| 纯品牌软文 | 夸品牌也要写代价、限制和用户账 |
| 本文将从三个方面分析 | 太像课程腔、公文腔、总结腔 |
| 只写消费升级、时代趋势、技术革命 | 宏大词不能替代具体商业账 |
| 把抽奖、福利、关注引导、后台回复、阅读原文、商务合作说明写进正文 | 这些是运营尾巴，不是风格 |
| 滥用离谱、魔幻、修仙、赛博、抽象 | 这些只是调味，不是正文骨架 |
| 把旧题材里的游戏、玄学、二次元话术硬套到消费商业文 | 梗要服务题材，不能反过来绑架题材 |
| 把合作文里的品牌口播、官方卖点、优惠说明当作风格 | 可学的是机制解释，不是广告话术 |
